# Insurance Claims Analysis Using Excel

## Project Overview

This project focuses on analysing insurance claims data using Microsoft Excel.

The aim is to understand claims patterns, examine the relationship between premiums and claims, and demonstrate how Excel can be used to generate useful insights for insurance decision-making.

## Project Objectives

- Analyse insurance claims across different policy types.
- Examine premium and claim amounts.
- Identify high-value claims.
- Calculate and interpret loss ratios.
- Summarise findings using PivotTables and charts.

## Tools and Techniques

**Tool:** Microsoft Excel

**Techniques used:**
- Data organisation and cleaning
- Excel formulas (IF and COUNTIF)
- Conditional categorisation of claims
- PivotTables
- Data summarisation
- Loss ratio calculations
- Data visualisation

## Dataset Description

The project uses a small practice dataset containing insurance-related information, including:

- Customer
- Age
- Policy Type
- Premium
- Claim Amount
- Number of Claims
- Claim Category

## Key Learning Outcomes

Through this project, I developed practical experience in:

- Organising and analysing structured data.
- Using Excel formulas to classify and summarise information.
- Comparing insurance premiums and claims.
- Understanding the importance of loss ratios in insurance analysis.
- Presenting data in a way that supports decision-making.
